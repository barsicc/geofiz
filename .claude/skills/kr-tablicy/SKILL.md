## 0. Отсчёты с планшета (если планшет ПЛ2010)
(`tools/pl2010*.py` требуют `pip install pymupdf` — в новой сессии поставить сразу; остальные инструменты — только numpy/PIL.)
```bash
python3 tools/pl2010.py 960.5 962.8        # max/min/mean БК, МБК, ИМ, СП, КВ в интервале
python3 tools/pl2010.py --at 945.6          # значения на глубине
python3 tools/pl2010_layers.py              # все 6 пластов: ρк, соседи, σ, ΔUсп, Eвм
```
- **hпл** = подошва − кровля (пересчитай! в методичке 944,0 − 942,2 записано как 1,4, верно 1,8).
- **ρк (БК)** — максимум против однородного пласта (для глины — минимум). На глаз преподаватель округляет: 56,8 → «60».
- **ρвм** = (ρвм′ + ρвм″)/2 — показания (плато) соседних пластов выше и ниже.
- **σк (ИК)** — экстремум (для высокоомного пласта — минимум σ). **σвм = (макс. σ выше + макс. σ ниже)/2** — так в методичке (75/140) и у семинара.
- **dс** — кавернограмма, мм → м (0,287).
- **СП:** линия глин ≈ 35,1 мВ от левого края (среднее максимумов в глинах). **ΔUсп = 35,1 − min СП** в пласте.
  На бумаге: X мВ = см·10/1,6 (стрелка 10 мВ = 1,6 см).
  **Eвм′/Eвм″** — отклонение от линии глин ближайшего «горба» СП в соседнем пласте; у глины ≈ 0. Eвм = среднее.
- Другой планшет (картинка) → снимать по калибровке шкал (как в `конспекты/ПЛ2010_…md`), отсчёты показывать числами.

## 1. БК (АБК-3) — колонки 3–11
```bash
python3 tools/bk.py --rk 60 --rvm 10 6.4 --rr 2 --d 0.287 --h 1.4
```
Номограмма — по h/dс, ближайшая из 4d/8d/16d/32d. Порядок: левое поле (ρвм/ρр; ρк/ρр) → параллельно кривым на край → горизонталь в правое поле до dс (см) → шифр = ρп/ρр; ρп = (ρп/ρр)·ρр.
Скрипт печатает и соседние номограммы для контроля. Точность ±5–10 %: на методичке 52,6 против 50; у семинара на 10–20 % выше.
Если «(!) вне поля» (глина, ρк < ρвм) — писать ρп ≈ ρк и пометку.

## 2. ИК (6Ф1) — колонки 3–10
```bash
python3 tools/ik.py --sk 45 --svm 75 140 --rr 2 --d 0.285 --h 1.6
```
σк → ρк и σвм → ρвм по кривой 6Ф1 (стр. 7) → поправка за скважину по полю ρр, шифр dс (стр. 8) → ρк^н.с → поправка за толщину по полю ρвм (0,6/1,2/6,0/12,0 — ближайшее), шифр h (стр. 9) → ρп^ИМ.
Поле ρр = 5 не оцифровано (6 линий на 5 подписей). При h > 2 м поправка мала: ρп ≈ ρк^н.с.

## 3. СП — колонки 3–20
1. Для коллектора **ρп = ρп^ИМ, ρзп = ρп^БК**, **ρвм — по ИМ (Ом·м, колонка 8 таблицы ИК)**, **Dзп = 2·Rис(БК) = 2 м**. Для плотного пласта ρп = ρп^БК, а в колонках 9, 10, 12, 13 ставится «–».
2. Отношения: ρвм/ρр, Dзп/dс, ρзп/ρр, hпл/dс, ρп/ρр.
3. Палетка ν:
   ```bash
   python3 tools/nu.py --choose 2.65 7 16     # → 15н (каждый параметр к ближайшему: ρвм/ρр∈{1;5}, D/dс∈{2;4;6}, ρзп/ρр∈{10;20;50;100})
   python3 tools/nu.py 15н 8.0 --c 7.6         # коллектор: X = hпл/dс, шифр = ρп/ρр
   python3 tools/nu.py 11в 47 --c 6.3          # плотный (без проникновения): 11в — ρвм/ρр=5, 11н — ρвм/ρр=1; X = ρп/ρр, шифр = hпл/dс
   ```
   ⚠ Подписи шифров на скане дают лишние «пересечения», и автонумерация сдвигается. **Всегда открывай картинку** `/tmp/nu_<id>_<X>.png` (Read) и проверяй, что пересечение ↔ шифр сопоставлены верно.
   Кривые, которые на этом X ещё не начались или уже кончились (на стр. 11 кривые 2 и 4 обрываются при ρп/ρр ≈ 25 и ≈ 45), выпадают из нумерации. Тогда `--skip` или экстраполяция вручную.
   Откалиброваны 11в, 11н, 15в, 15н. Для остальных: `python3 tools/nu.py --ruler 17в` → снять 4 угла по линейке → вписать `k` в `CAL` в `tools/nu.py` (2 мин).
   Равенство расстояний (например, ρзп/ρр = 15) — бывают обе палетки. Семинар брал бо́льшую (20).
4. ```bash
   python3 tools/sp.py --kmax --k18 69 --t 30 --rf 1.5 --rv 0.19    # Kсп,t = 69·303/291 = 71,8; ΔEмакс = 72·lg(1,5/0,19) = 65 мВ
   python3 tools/sp.py --du 29.6 --evm 4.4 0 --nu 0.51 --emax 65   # ΔEсп, αсп, ηгл
   ```
   ρф — палетка 3-I (ПАЛ стр. 25) по ρр и t; ρв — палетка 1-I (ПАЛ стр. 24) по Cв и t (таблицы — `конспекты/ПАЛ_…md`, стр. 24).
   В методичке при ρр = 2 и 30 °C взято ρф = 1,5, при Cв = 30 кг/м³ и 30 °C взято ρв = 0,19.
5. Формулы (текстом):
   - ΔEсп = (ΔUсп − Eвм)/ν + Eвм;
   - αсп = ΔEсп/ΔEсп,макс;
   - ηгл = 1 − αсп;
   - Kсп,t = Kсп,18·(t + 273)/291;
   - ΔEсп,макс = Kсп,t·lg(ρф/ρв); минус опускаем, так как отклонение влево от линии глин.
