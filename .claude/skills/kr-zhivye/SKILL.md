# Живые ответы на КР

1. **Без подтверждений.** Коротко ответить в чат → сразу дописать в `КРN/ЖИВЫЕ.md` (новое сверху; N — номер КР, для большой итоговой — `КР2/` если не сказано иное, создать папку при необходимости) → `git add` → commit → **push в `main`** (`git push origin HEAD:main`; если отклонён — `git pull --rebase origin main` и снова push). Ничего не переспрашивать.
2. **Каждый ответ самодостаточен**, без ссылок на другие файлы.
3. **Таблицы КР (БК/ИК/СП)** — по скиллу `kr-tablicy`: сначала `КР/ПЛ2010_ГОТОВЫЕ_ТАБЛИЦЫ.md`, при отличиях — пересчёт `tools/*.py`. В ответ: заполненная таблица Markdown (все колонки по номерам, как на бланке) + 2–4 строки «как получено» (какая номограмма/палетка, ключевые промежуточные числа).
4. **Картинки — только если просят** «нарисуйте/покажите построение». Тогда построение поверх картинки палетки (PIL) → `КРN/img/…png` → `![](img/…png)` под вопросом. По умолчанию — числа.
5. **Формулы — обычным текстом с Unicode** (ΔEсп = (ΔUсп − Eвм)/ν + Eвм; ρп = (ρп/ρр)·ρр), не LaTeX.
6. Строго на спрошенное, коротко; задачи — формула → подстановка → ответ с единицами.
7. Если фото нечёткое — написать, что прочитано («σк = 45 (?)»), и решать с этим, не ждать.
8. Порядок поиска по теории: `КАРТА.md` → `ФОРМУЛЫ.md` → `конспекты/` (grep). Палетки — `конспекты/ПАЛ_…md`.

Шаблон записи:
```
## Вопрос N (HH:MM) — <кратко>
<таблица / ответ>
Как получено: …
```
