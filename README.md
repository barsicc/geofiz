# geofiz — Геофизические исследования скважин (ГИС)

Материалы курса ГИС / промысловой геофизики: лекции, практика (палетки, планшет), литература — в виде, удобном для работы с Claude. Устроено так же, как репозиторий `dolov`.

- **[КАРТА.md](КАРТА.md)** — навигатор: файлы, темы → конспекты и слайды, каталог рисунков, пробелы.
- **[ФОРМУЛЫ.md](ФОРМУЛЫ.md)** — все формулы и константы со ссылками.
- **[конспекты/](конспекты/)** — полные расшифровки (формулы LaTeX, таблицы, описания рисунков, оцифровка графиков).
- **[конспекты/ЛИТ_План_больших_книг.md](конспекты/ЛИТ_План_больших_книг.md)** — что загружать из трёх больших книг (≈ 280 стр. вместо ~1050).
- `01_Лекции/`, `02_Практика/`, `03_ДЗ/`, `04_Литература/` — исходные файлы; `рисунки/` — страницы со схемами.
- **`upload/`** — сюда новые материалы, затем «разбери upload».
