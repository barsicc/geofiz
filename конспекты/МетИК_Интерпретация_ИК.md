# МетИК — Методичка «Интерпретация диаграмм метода индукционных зондов» (семинар)

**Источник:** `02_Практика/МетИК_Интерпретация_ИК.pdf` (7 стр., Word; исходное имя «Интерпретация_диаграмм_индкуционнго_каротажа.pdf»). Рисунки: `рисунки/МетИК/стр004.jpg` (рис. 1 — планшет), `стр005.jpg` (рис. 2 — скин-эффект = ПАЛ стр. 7), `стр006.jpg` (рис. 3 — поправка за скважину = ПАЛ стр. 8), `стр007.jpg` (рис. 4 — поправка за толщину/вмещающие = ПАЛ стр. 9).
**Содержание:** пошаговое заполнение таблицы ИК (10 колонок) на примере пласта № 1 (942.2–944.0 м).

⭐ **Ключевое**
- Колонки: 1 № | 2 интервал | 3 h | 4 σк (мСим/м) | 5 σвм | 6 dс | 7 ρк | 8 ρвм | 9 ρк^н.с | 10 ρп по ИМ.
- **σк** — экстремальное (для высокоомного пласта — минимальное) значение; **σвм = (σвм′ + σвм″)/2**. В примере σвм′ = 75, σвм″ = 140 — это **максимумы** σ в соседних пластах (у пробника так же: 75/140, 146/155, 156/166).
- Цепочка: σ → ρ по кривой **6Ф1** (рис. 2; скин-эффект) → **поправка за скважину** (рис. 3: группа кривых по ρр, шифр — dс в м) → ρк^н.с → **поправка за толщину** (рис. 4: группа по ρвм = 0,6; 1,2; 6,0; 12,0 — ближайшая, шифр — hпл в м) → **ρп^ИМ**.
- Пример: σк = 43 → ρк = 23; σвм = 107,5 → ρвм = 7,5; ρр = 2, dс = 0,287 (между 0,25 и 0,30) → ρк^н.с = 20; ρвм ≈ 6 → поле 6,0, h = 1,4 (между 1,25 и 1,5) → **ρп^ИМ = 23 Ом·м**.
- Инструмент: `python3 tools/ik.py --sk 43 --svm 75 140 --rr 2 --d 0.287 --h 1.4` → 20,7 / 7,8 / 17,9 / 18,8. Оцифровка даёт на 10–15 % ниже рисованных стрелок. Для пробника совпадает с семинаром (17,5 против 18).

## Интерпретация диаграмм метода индукционных зондов

### 1. Выделение объектов интерпретации на диаграммах трехэлектродных зондов бокового каротажа.
Пласт № 1 (рисунок 1) находится в интервале 942.2 – 944.0 м. Рассчитываем его толщину

944.0 − 942.2 = 1.4 м *(прим.: верно 1,8 м)*

Полученное значение записываем в колонку 3.

### 2. Снятие отсчетов σк с диаграммы индукционного метода.
Пласт № 1 однородный по удельной электропроводности (рисунок 1), поэтому снимаем экстремальное значение кажущейся удельной электропроводности.

σк = 43 мСим/м

Полученное значение записываем в колонку 4.

### 3. Определение удельной электропроводности вмещающих пород σвм по диаграмме индукционного метода.
Удельная электропроводность вмещающих пород рассчитывается как среднее арифметическое между показаниями выше- и нижележащих пластов (рисунок 1).
Удельное сопротивление *(прим.: электропроводность)* вышележащего пласта – σвм′ = 75 мСим/м.
Удельное сопротивление вышележащего *(прим.: нижележащего)* пласта – σвм″ = 140 Ом·м *(прим.: мСим/м)*.

$$\sigma_{вм}=\frac{\sigma'_{вм}+\sigma''_{вм}}{2}=\frac{140+75}{2}=107.5\ мСим/м$$

Полученное значение записываем в колонку 5.

### 4. Определение диаметра скважины по данным кавернометрии скважины.
Значение диаметра скважины снимается с кавернограммы.

dс = 287 мм = 0.287 м

Полученное значение записываем в колонку 6.

### 5. Переход от удельной электропроводности к кажущемуся сопротивлению с учетом скин-эффекта.
Переход от удельной электропроводности к кажущемуся сопротивлению осуществляется по зависимостям ρк = ƒ(σк), полученным для зондов разного типа (рисунок 2). Запись диаграммы индукционного метода проведена зондом 6Ф1, поэтому используем кривую с шифром 6Ф1.

σк = 43 мСим/м → ρк = 23 Ом·м — записываем в колонку 7.
σвм = 107.5 мСим/м → ρк *(прим.: ρвм)* = 7.5 Ом·м — записываем в колонку 8.

<!-- стр. 2 -->
### 6. Приводим показания индукционного метода к условиям непроводящей скважины.
Зависимости, представленные на рисунке 3, различаются удельным сопротивлением раствора. А шифр каждой кривой – диаметр скважины в метрах.
Исследуемая скважина заполнена проводящим раствором с удельным сопротивлением 2.0 Ом·м. Диаметр скважины против пласта № 1 – 0.287 м. Выбираем группу кривых с шифром ρр = 2.0 Ом·м и, интерполируя между кривыми с шифрами dс = 0.25 м и dс = 0.3 м, находим кажущееся сопротивление пласта, приведенное к условиям так называемой непроводящей среды, то есть скважины, заполненной непроводящим раствором.

ρк^н.с = 20 Ом·м — записываем в колонку 9.

### 7. Приводим показания к условиям пласта бесконечной толщины.
Зависимости, представленные на рисунке 4, различаются удельным сопротивлением раствора *(прим.: вмещающих пород)*. А шифр каждой кривой – толщина пласта в метрах.
Удельное сопротивление вмещающих пород – ρк *(прим.: ρвм)* = 7.5 Ом·м. Толщина пласта – 1.4 м. Выбираем группу кривых с шифром ρвм = 6.0 Ом·м и, интерполируя между кривыми с шифрами hпл = 1.25 м и hпл = 1.53 м *(прим.: 1.5)*, находим удельное сопротивление пласта по индукционному методу.

ρп^ИМ = 23 Ом·м — записываем в колонку 10.

По рассмотренному алгоритму необходимо получить удельное сопротивление пластов №№ 2 – 6. Результаты интерпретации вносить в таблицу 1.
