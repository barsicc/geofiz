## Стр. 2–5. Номограммы h = 4d, 8d, 16d, 32d для определения ρп. Зонд АБК-3. Шифр кривых — ρп/ρр ⭐
🖼 Каждая номограмма — из двух полей (логарифмические оси):
- **Правое поле:** ось X — **dс, см** (10–30), семейство убывающих кривых с шифром **ρп/ρр** (5, 10, 25, 50, 100, 250, 500, 1000 — подписаны, между ними промежуточные). Кривые убывают с ростом dс (в большой скважине влияние проводящего раствора сильнее).
- **Левое поле:** ось X — **ρвм/ρс** (1 — 2,5 — 5 — 8 — 10 — 15 — 25 — 50, ρс = ρр — сопротивление раствора в скважине), ось Y — **ρп/ρс** (здесь по смыслу кажущееся ρк/ρс — «мостик»; 1…1000+, 3 декады). Кривые возрастают от ρвм/ρс = 1 и выполаживаются к ρвм/ρс ≈ 30–50 (влияние вмещающих пород исчезает, когда они высокоомные). Горизонтальные продолжения кривых соединяют левое и правое поля.
- Отличие страниц — **толщина пласта h в диаметрах скважины d**: 4d (тонкий, сильное влияние вмещающих — кривые в левом поле сильно наклонены), 8d, 16d, 32d (мощный — кривые почти горизонтальны, влияние вмещающих мало).

**Как пользоваться (стандартная схема для двухполевых номограмм БК; в источнике не расписано — уточнить на семинаре):**
1. Снять с диаграммы БК против середины пласта **ρк**, знать ρр (= ρс, раствор при t пласта), dс (по кавернограмме, см), ρвм (БК во вмещающих глинах), толщину h → выбрать страницу по h/dс (4, 8, 16, 32 — ближайшая).
2. Вычислить ρк/ρр и ρвм/ρр.
3. В **левом** поле: от точки ρвм/ρр на оси X подняться до уровня ρк/ρр по оси Y, найти кривую, проходящую через эту точку (интерполировать между соседними) → пройти по кривой вправо до её горизонтального участка и далее в **правое** поле.
4. В **правом** поле: на вертикали dс найти точку пересечения с этой линией → прочитать шифр кривой **ρп/ρр**, проходящей через точку (интерполируя в логарифмах).
5. **ρп = (ρп/ρр)·ρр**.

## Стр. 7. Зависимость ρк = f(σк) для учёта скин-эффекта ⭐
🖼 Билогарифмический график: X — **ρк, Ом·м** (0,2–100), Y — **σк, мСим/м** (8–2500). Кривые для зондов **4И1** (верхняя), **8И1.4**, **6Ф1** (почти совпадают), **4Ф1** (ниже, загибается при малых ρ), **4Ф1.1** (колоколообразная, максимум σ ≈ 48 при ρк ≈ 5, только для ρк > 2,3). Без скин-эффекта было бы σ = 1000/ρ (прямая); из-за скин-эффекта при низких ρк (высокой проводимости) прибор показывает **меньше**, чем 1000/ρк.

Для **6Ф1** (снято с картинки, ±5 %):

| ρк, Ом·м | 0,2 | 0,3 | 0,5 | 0,7 | 1 | 2 | 3 | 5 | 10 | 20 | 50 | 100 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| σк (6Ф1), мСим/м | 1750 | 1450 | 1100 | 850 | 650 | 360 | 250 | 160 | 85 | 45 | 19 | 9,5 |

**Как пользоваться:** на диаграмме ИК — проводимость σк (мСим/м). Найти σк на оси Y → горизонталь до кривой 6Ф1 → вниз → **ρк**. При σк < ~50 мСим/м можно считать ρк ≈ 1000/σк.

## Стр. 8. Палетка поправки ρк за электропроводность глинистого раствора (индукционный зонд 6Ф1). Шифр кривых — диаметр скважины, м ⭐
🖼 Четыре одинаковых по устройству поля (сдвинутые «лесенкой»), каждое для своего **ρр = 0,5; 1; 2; 5 Ом·м**. В каждом поле: X — **ρк** (измеренное, нижняя/верхняя шкала со своим началом, лог.), Y — **ρк^н.с** (исправленное за скважину, общая лог. шкала 0,2–100). Пучок кривых с шифром **dс = 0,15; 0,20; 0,25; 0,30; 0,35 м**: при малых ρк кривые идут вдоль биссектрисы (поправка мала), при больших ρк расходятся: по картинке **верхняя кривая — dс = 0,15 м, нижняя — 0,35 м** (при одном ρк исправленное значение тем больше, чем меньше dс). Пример (поле ρр = 1): ρк = 50 → ρк^н.с ≈ 60–70 (dс 0,15–0,2) и ≈ 40 (dс 0,35).

**Как пользоваться:** выбрать поле с нужным ρр (интерполировать между полями) → на его оси ρк отложить измеренное значение → вверх до кривой своего dс → влево **ρк^н.с**.

<!-- стр. 9 -->
## Стр. 9. Палетка поправки ρк за электропроводность вмещающих пород (индукционный зонд 6Ф1). Шифр кривых — толщина пласта, м ⭐
🖼 Четыре поля «лесенкой» для **ρвм = 0,6; 1,2; 6,0; 12,0 Ом·м**. X — **ρк^н.с** (после поправки за скважину), Y — **ρк^испр** (лог.). Кривые с шифром **h = 0,75; 1,0; 1,25; 1,5; 2,0 м**. Все кривые пересекаются в точке ρк^н.с = ρвм (там поправка нулевая); выше этой точки ρк^испр > ρк^н.с (тонкий высокоомный пласт «занижен» вмещающими), тем сильнее, чем тоньше пласт (кривая 0,75 — самая крутая). При h > 2 м поправка мала.

**Как пользоваться:** выбрать поле по ρвм → ρк^н.с по оси X → до кривой h → **ρк^испр ≈ ρп** (если нет глубокого проникновения).

## Стр. 10. Палетки для интерпретации данных метода потенциалов собственной поляризации
Титульный лист раздела.

### Теория (что нужно для палеток СП) ⭐
- Статическая амплитуда СП: $E_{сп} = -K_{сп}\lg\dfrac{\rho_ф}{\rho_в}$ (стр. 23); $K_{сп}$ ≈ 69,6 мВ при 18 °С для NaCl, при температуре пласта $K_{сп,t} = K_{сп,18}\cdot\alpha_t$ (стр. 22).
- Измеренная амплитуда ΔUсп меньше статической из-за конечной толщины пласта, проникновения, сопротивлений: $\Delta U_{сп} = \nu_{сп}\cdot E_{сп}$, где **νсп ≤ 1** — поправочный коэффициент (стр. 11–21). Отсюда $E_{сп} = \Delta U_{сп}/\nu_{сп}$.
- Обозначения на палетках: H — толщина пласта; dс — диаметр скважины; D — диаметр зоны проникновения; ρп, ρвм, ρзп, ρр — сопротивления пласта, вмещающих, зоны проникновения, раствора.

## Стр. 11. Палетки для определения коэффициента νсп при отсутствии проникновения в пласт ⭐
🖼 Две палетки (верхняя: **ρвм/ρр = 5, D/dс = 1**; нижняя: **ρвм/ρр = 1, D/dс = 1**). Ось X — **ρп/ρр** (лог., 1–150), ось Y — **νсп** (0–1). Убывающие кривые с шифром **H/dс = 2; 4; 6; 8; 10; 15; 20; 30**. Чем толще пласт (H/dс больше) и чем меньше ρп/ρр, тем νсп ближе к 1.

Ориентиры (верхняя, ρвм/ρр = 5): H/dс = 2: ρп/ρр = 1 → 0,87; 10 → 0,50; 25 → 0,25. H/dс = 4: 10 → ~0,68; 40 → ~0,28. H/dс = 10: 10 → ~0,85; 100 → ~0,40. H/dс = 30: 100 → ~0,8; 150 → ~0,7.
Нижняя (ρвм/ρр = 1) — кривые на ~0,05–0,1 ниже при тех же параметрах.

🖼 Каждая палетка: ось X — **H/dс** (лог., 2–30), ось Y — **νсп** (0–1); возрастающие S-образные кривые с шифром **ρп/ρр = 0,1; 5; 10; 20; 40; 60; 100; 150** (верхняя — 0,1). Параметры палеток:

|---|---|---|
| 12 | 1; 2; 10 | 1; 2; 20 |
| 13 | 1; 2; 50 | 1; 4; 10 |
| 14 | 1; 4; 20 | 1; 4; 50 |
| 15 | 1; 6; 10 | 1; 6; 20 |
| 16 | 1; 6; 50 | 1; 6; 100 |
| 17 | 5; 2; 10 | 5; 2; 20 |
| 18 | 5; 2; 100 | 5; 4; 10 |
| 19 | 5; 4; 20 | 5; 4; 100 |
| 20 | 5; 6; 10 | 5; 6; 20 |
| 21 | 5; 6; 50 | 5; 6; 100 |

Ориентиры, стр. 12 верх (1; 2; 10): ρп/ρр = 0,1: H/dс = 2 → 0,43; 4 → 0,70; 10 → 0,92. ρп/ρр = 10: 4 → 0,50; 10 → 0,80; 20 → 0,93. ρп/ρр = 150: 8 → 0,2; 20 → 0,55; 30 → 0,72.

## Стр. 22. Номограмма для определения Kсп аномалии СП и температурного коэффициента αt при температуре t °С пласта ⭐
🖼 Шкалы (слева направо): **t, °С** (−10…180) с парной шкалой **αt** (0,95…1,5); кривая шкала **Kсп,18°С** (10…100); прямая шкала **Kсп,t** (0…200); справа — кривая шкала **t, °С** (0…250). Номограмма с выравнивающими точками: прямая через t (левая шкала) и Kсп,18 пересекает шкалу Kсп,t.

Связь (проверено по делениям шкалы): $\alpha_t = \dfrac{273 + t}{291}$ (t = 18 → 1,0; 80 → 1,21; 133 → 1,40; 163 → 1,50) и **Kсп,t = Kсп,18·αt**. Пример: t = 60 °С → αt = 1,144; Kсп,18 = 69,6 → Kсп,60 ≈ 79,6 мВ.

<!-- стр. 23 -->
## Стр. 23. Номограмма для решения уравнения $E_{СП} = -K_{СП}\cdot\lg\dfrac{\rho_ф}{\rho_в}$ ⭐
🖼 U-образная номограмма: левая дуга — **ρф/ρв** (1…100, для отрицательных Eсп) и парная шкала 0,01…1 (для положительных); средняя прямая — **ΔEсп** (0…200 мВ, «−» слева, «+» справа); правая дуга — **Kсп** (10…100). Прямая через Kсп и ΔEсп пересекает шкалу ρф/ρв.

Проще посчитать: $\dfrac{\rho_ф}{\rho_в} = 10^{-E_{сп}/K_{сп}}$ (при отрицательной аномалии Eсп < 0 → ρф/ρв > 1). Пример: Eсп = −80 мВ, Kсп = 80 → ρф/ρв = 10 → ρв = ρф/10.

## Стр. 24. Зависимость удельного сопротивления ρв растворов NaCl при различной температуре ⭐
🖼 = Л03 сл. 6 (описание и как пользоваться — в `конспекты/Л03_УЭС_пород.md`, сл. 6). Ось Y — ρв (0,01–100 Ом·м), ось X — C (кг/м³, 0,1–300), Cн (кг-экв/м³), δ²⁰в − 1; шифр — t, °С (0…200).
Применение: (1) ρв по минерализации и температуре; (2) **пересчёт ρ раствора/фильтрата с одной температуры на другую**: найти точку (ρ, t₁) → по вертикали (та же концентрация) до кривой t₂ → новое ρ.
Для разбавленных растворов можно формулой Арпса *(общие знания)*: $\rho_{t_2} = \rho_{t_1}\dfrac{t_1 + 21{,}5}{t_2 + 21{,}5}$ (t в °С).

## Стр. 25. Палетка для определения ρф по известному ρр. Шифр кривых — t, °С
🖼 Повёрнутый билогарифмический график: ось **ρр, Ом·м** (0,03–5) и ось **ρф, Ом·м** (0,02–5). Пучок кривых t = 0, 10, 20, 30, 40, 50, 60, 80, 100, 120 °С близ биссектрисы: при ρр ≈ 0,1–0,3 кривые перекручиваются (S-образно), при больших ρр **ρф немного меньше ρр** (≈ 0,8–0,9·ρр), при малых — близко к ρр.

## Стр. 26. Палетка для нахождения истинных ρв по (ρв)э, определённой по диаграмме UСП
🖼 Билогарифмический: X — **(ρв)э, Ом·м** (0,001–1) — «эквивалентное» сопротивление, полученное из Eсп по номограмме стр. 23; Y — **ρв, Ом·м** (0,005–3). Шифр — t = 25, 40, 75, 100, 150, 200 °С. Все кривые проходят через точку ≈ (0,1; 0,1): при (ρв)э > 0,1 (пресные воды, пунктир) ρв > (ρв)э; при (ρв)э < 0,1 (рассолы) ρв > (ρв)э тоже, кривые выполаживаются (например, t = 25: (ρв)э = 0,01 → ρв ≈ 0,045; t = 100: 0,01 → ≈ 0,02).

## ⭐ Алгоритм «ρв по СП» (типовое ДЗ)
1. По диаграмме СП: провести **линию глин** (нулевая линия) и **линию песков** → снять амплитуду ΔUсп пласта (мВ, по масштабу дорожки, обычно «10 мВ» на клетку — смотреть легенду).
2. Толщина пласта H (по границам на середине аномалии СП), dс (кавернограмма), ρп (БК/ИК), ρвм, ρр, D и ρзп (если есть МБК/БКЗ) → νсп по стр. 11–21 → **Eсп = ΔUсп/νсп**.
3. t пласта → αt и **Kсп,t** (стр. 22).
4. ρр → **ρф** (стр. 25; при температуре пласта — пересчёт по стр. 24).
5. $\rho_ф/\rho_в = 10^{-E_{сп}/K_{сп,t}}$ (стр. 23) → **(ρв)э = ρф / (ρф/ρв)**.
6. (ρв)э → **ρв** (стр. 26), по стр. 24 — минерализация C.
7. Дальше: Pп = ρп/ρв (для водоносного пласта) → Kп (Л03 сл. 9); для продуктивного — Pн = ρп/(Pп·ρв) → Kв (Л03 сл. 15).

## ⭐ Алгоритм «ρп по ИК (6Ф1)»
σк (мСим/м) → ρк (стр. 7, скин-эффект) → поправка за скважину ρк^н.с (стр. 8, по ρр и dс) → поправка за вмещающие ρк^испр (стр. 9, по ρвм и h) → ρп.

## ⭐ Алгоритм «ρп по БК (АБК-3)»
ρк, ρр, dс, ρвм, h → страница по h/d (стр. 2–5) → ρп/ρр → ρп.
