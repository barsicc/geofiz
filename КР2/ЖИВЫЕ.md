Как получено:
- БК: ρк/ρр = 54/2,5 = 21,6; ρвм/ρр = 39/2,5 = 15,6; hпл/dс = 2,4/0,3 = 8 (номограмма 8d). ρп/ρр ≈ 32, ρп = 32·2,5 ≈ 80 Ом·м.
- ИК: ρк = 13,4 и ρвм = 27 по кривой 6Ф1 (стр. 7); поправка за скважину (стр. 8) ρк^н.с ≈ 12,4 (поле ρр = 2 даёт 12,1, при ρр = 5 поправка меньше, интерполяция к 2,5); поправка за вмещающие (поле ρвм = 12, h = 2,4 — выше шифров, поправка мала) ρп^ИМ ≈ 12,8.
- Сравнение: ρп^БК ≈ 80 > ρп^ИМ ≈ 12,8, значит ρзп > ρп — повышающее проникновение (пласт-коллектор). ρп = 12,8, ρзп = 80 Ом·м.
- ν по палетке стр. 20 (ρвм/ρр = 5; D/dс = 6; ρзп/ρр = 20): X = hпл/dс = 8 → кривая ρп/ρр = 1 даёт 0,66, кривая 10 даёт 0,59; для ρп/ρр = 5,1 получаем ν ≈ 0,61.
- ΔEсп = (ΔUсп − Eвм)/ν + Eвм = (−38 + 24)/0,61 − 24 = −46,9 ≈ −47 мВ.
- Kсп,t = 55·(80 + 273)/291 = 66,7 ≈ 67 мВ; ΔEсп^макс = 66,7·lg(1,95/0,2) = 66,7·0,989 = 66,0 мВ.
- αсп = 46,9/66,0 = 0,71; ηгл = 1 − αсп = 0,29.
