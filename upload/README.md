# upload — входящие

Загружай сюда новые материалы как есть (PDF, PPT/PPTX, DOCX, XLSX, фото), с любыми именами.
Затем попроси Claude: **«разбери upload»** — определит, что это, переименует, разложит, сделает полную расшифровку и обновит карту (регламент — `CLAUDE.md`).
Фрагменты больших книг называй с печатными страницами: `Латышова2007_стр113-132.pdf` (план — `конспекты/ЛИТ_План_больших_книг.md`).
